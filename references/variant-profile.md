# VoxEasy Profile

- 版本：`4.13-public.1`
- 调用：允许自动触发
- 定位：通用、稳定、公开发布的 VoxEasy
- 推荐模型：`Google Flow / Omni Flash`
- 推荐比例：`9:16`
- 推荐风格：`vox-standard`
- 可选风格：`vox-standard`、`american-comic`、`monument-pastel`、`vintage-newspaper`、`pixel-theater`、`custom`
- 叙事偏好：根据内容选择，不固定套用模板

## 视觉优先级

- 内容匹配的表达方式
- 清楚的场景锚点或隐喻映射
- 稳定动作
- 可读画面

## 定制约束

- 同一条视频默认统一风格
- 只有用户明确要求才允许混合风格

Profile 只设置版本边界和推荐值，不得跳过两次确认、时间轴验证、文字白名单或用户明确选择。用户要求不在可选风格内的风格时，建议改用 `$voxeasy` 或 `$voxeasy-lab`，不得静默越界。
