# 扩展风格公共合同

扩展风格共用字幕含义、完整时间、已确认的表达方式、场景锚点和 Prompt 精度，不共用标准 Vox 的构图与材质。

1. 不改变已确认字幕、事实、文字和 `4/6/8/10` 秒时长。
2. 每个 Shot 先确定核心信息，再按 [`../expression-routing.md`](../expression-routing.md) 确认 `direct`、`story` 或 `metaphor`；只有隐喻模式建立概念映射。
3. 只使用所选风格转译已确认的表达方式、构图、主体形态、材质、动作和镜头语言，不混入其他风格，也不擅自改变表达方式。
4. 4/6/8 秒两段动作，10 秒最多三段；每个 Shot 只发生一次主要转变。
5. 实际比例和方形安全区服从主文件。
6. 最终 Prompt 完整满足 [`../output-contract.md`](../output-contract.md)。

需要 `1:1` 裁切时，把主体、人物、动作和文字放在中央方形安全区；安全区外只延伸非关键背景。Prompt 与生成接口仍写实际 `9:16` 或 `16:9`。

所有颜色 Hex 只能作为不可见生成控制。不得把 Hex、颜色代码或调试文字渲染进画面。
